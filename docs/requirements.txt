پیش‌نیازهای اجرا و توسعه پروژه SMART_FACTORY

سخت‌افزار / شبیه‌سازی:
- STM32F103 (Blue Pill)
- Proteus 8
- Keil uVision یا ARM GCC برای کامپایل فریمور

فریمور:
- زبان C
- HAL Library استفاده شده
- ارتباط سریال UART/USART بین برد و سیستم مرکزی

سیستم مرکزی:
- ویندوز
- ارتباط با پورت COM
- دیتابیس محلی

اپلیکیشن پایتون:
- Python 3.9 به بالا
- pyserial
- pip install -r requirements.txt

نحوه اجرا:
1. کلون پروژه از گیت‌هاب
2. باز کردن هر فایل پروتئوس داخل پوشه subsystems
3. کامپایل فریمور و گرفتن فایل hex
4. اجرای برنامه سیستم مرکزی
5. اجرای main.py برای اپلیکیشن پایتون

نکته: پورت COM باید توی پروتئوس، سیستم مرکزی و پایتون یکسان باشه.
هر زیرسیستم جدا از بقیه قابل اجرا و تست هست.
